# Cursor Instructions

## Shell documentation

Follow `docs/shell-documentation-standard.md` when editing dotfiles shell aliases and functions.

Rules:

- Preserve command behavior unless explicitly asked to change it.
- Do not rename, remove, or reorder commands during documentation-only tasks.
- Preserve existing file and section organization.
- Infer categories from module names and nearby headings.
- Add only meaningful annotations.
- Do not invent undocumented behavior.
- Keep examples safe and free of credentials or sensitive values.
- Prefer `@internal` for implementation helpers that should not appear in the normal manual.
